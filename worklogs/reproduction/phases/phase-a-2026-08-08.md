## Decisions

- Reproduction target: WN18RR with pattern control.
- Runtime baseline: Python 3.11, PyTorch 2.6/CUDA 12.4, TRL 0.16.
- Model assumption: randomly initialized GPT-2 small structure, 12 layers, hidden
  size 768, 12 heads. The authors' missing `hug_model/config.json` is not inferred.
- Experiment semantics come from one strict YAML per run. Runtime storage roots
  come from `CTRLHGEN_DATA_ROOT`, `CTRLHGEN_CHECKPOINT_ROOT`, and
  `CTRLHGEN_RUN_ROOT`.

## Implementation log

- Added strict single-YAML experiment configuration with canonical semantic
  hashes and runtime roots supplied only through environment variables.
- Rebuilt KG loading around cache-first offline reuse, canonical seeded splits,
  inverse-edge expansion after exclusive splitting, and auditable manifests.
- Made sampling bounded and worker-count independent; added stable task seeds,
  sorted records/answers, structured failure reports, and base/augmented/merged
  artifacts with provenance.
- Replaced device-bound augmentation with train-only raw-record transforms for
  `up`, `3in`, `pni`, `pin`, and `inp`.
- Added a contiguous reproduction tokenizer, a fixed `PreparedBatch` contract,
  canonical `ConditionSpec`, and an explicit random GPT-2 small configuration.
- Added AdamW SFT with optimizer-step warm-up, portable directory checkpoints,
  parent/resume/test semantics, explicit parse status, stable evaluation JSONL,
  named GRPO rewards, persistent reward-component logging, and Trainer resume.
- Added reproduce wrappers, pinned direct dependencies, test markers, and a
  Phase A/Phase B/legacy support boundary in the README.
