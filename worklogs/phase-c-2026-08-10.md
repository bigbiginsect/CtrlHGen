### 2.4 后续定位到的实现事实

这些事实是在第一次 run 结束后的 checkpoint round-trip、真实数据 overfit diagnostic 和
回归测试中得到，不应误写成仅凭上述 loss 曲线即可推出：

1. validation generation 曾把 fast tokenizer 切到 left padding；Python 属性恢复后，
   Rust backend padding 状态仍可能随 checkpoint 保存。
2. 旧 conditional 加载该 tokenizer 后，pair 与 prompt 的 mask 长度错位；检查训练 batch
   时，target 和 `END` 被 mask，`END` active-label 数量为 0。
3. 一个延长至 100 epoch 的旧契约诊断中，loss 可降到约 0.006，但仍为 0 EOS/0 parse。
4. 修复后的 contract 要求 active labels 精确等于 `target + END`，训练固定 right
   padding，generation 的 left padding 只在受控作用域中存在；format-v2 checkpoint
   还校验 tokenizer/hash 和生成健康指标。

## 5. 可供后续复核的观察与问题

以下是从数据直接可见、但仍允许不同解释的观察：

1. 第一次 unconditional 的 parse 在 20 epoch 内刚开始上升，语义集合指标仍接近零；
   同时，后续诊断确认 conditional 存在独立的 label-mask 错误。训练预算和实现错误在
   第一次 run 中同时存在，不能仅凭最终零指标衡量二者各自贡献。
2. 第二次的 parse/EOS 达到较高水平，说明“能够结束并形成可解析表达式”与语义集合
   重合、condition adherence 不是同一个训练现象。
3. 第二次 unconditional 的 train loss 持续下降，validation loss 在约 epoch 40 后总体
   上升；与此同时，parse/Jaccard 在较长区间仍继续改善后进入波动。如何定义过拟合或
   early-stop 目标，取决于更看重 teacher-forced loss 还是生成指标。
4. conditional 的 Pattern Accuracy 从 0.237 增长到 0.335，Jaccard 大致维持在
   0.345--0.351；train loss 显著下降而 validation loss 缓慢上升。它既不表现为完全
   无学习，也没有达到论文参照值。
5. sampled 相比 greedy 的集合重合指标更低，而 Pattern Accuracy 近似不变。后续可检查
   逐 pattern、实体覆盖、生成多样性和采样参数，而不应只看单个聚合数。
6. small 每 pattern 1,024 个 train query；仓库 full profile 是 8,000 个，约 7.8 倍。
   数据多样性是一个待验证解释，但当前三次 run 不是只改变数据规模的消融，不能据此
   单独证明因果。
7. 仍需考虑原模型宽度/heads 的实现假设、论文 query 数和 seed、unseen-entity mapping、
   generation 参数、单 seed 波动及仅 train augmentation 等开放项。
8. 第三次相对 v2 的 Pattern Accuracy 和 Smatch 提高，但 Jaccard、Dice、Overlap 下降；
   这支持“结构/condition adherence 与答案集合重合不是同一现象”，但不建立因果解释。
9. 当时没有 GRPO 配对结果，并建议若直接继续 Phase D 应使用 v3 `conditional-best`。
   C-IV 后该建议已被第 8.6 节取代：后续正式 parent 应为 C-IV conditional-best。

### 8.6 结论与后续边界

在模型、optimizer、LR、scheduler、batch、seed、validation/test 和 selection 均固定时，
实体 train 覆盖提高 46.45 个百分点，greedy 三项集合指标相对 v3 提高约 0.33--0.37；
Pattern Accuracy 同时从 `0.5883` 提高到 `0.9441`。因此，**训练数据覆盖不足是 v3 当前的
主要瓶颈**，扩大数据显著改善语义集合指标，且控制能力不但保持而且明显加强。

它不是唯一剩余瓶颈：三项集合指标仍低于论文 w/o RL 约 0.11--0.12，`pin`、`inp`、
union sampled 和长结构仍有空间，并且结论只有 seed 42。基于已形成的健康、强 SFT parent，
**值得在后续独立任务中从 C-IV conditional-best 进入 GRPO**；GRPO 必须与本轮 frozen
SFT-only 配对并预先冻结 gate/test 契约。本任务没有进入或试跑 GRPO。
